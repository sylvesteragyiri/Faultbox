Connection URL

  • redis://redis:6379 for a server without a password.
  • redis://:password@redis:6379/0 for a password and database number.
  • redis://user:password@redis:6379 for a Redis 6+ ACL user.
  • rediss://… for TLS. The certificate must be valid for the host name.

What Faultbox reads

  • One INFO command per check: memory used, maxmemory, connected clients, keys per database, and uptime.
  • It never reads keys or values. An ACL user only needs +info (and +select for a non-zero database).
  • Faultbox must be able to reach the server from its own host or container network.

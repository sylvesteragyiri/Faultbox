# Faultbox brand

## Idea

Faultbox catches application faults and keeps their signals together. The mark
uses a pulse held inside a box: the box stands for self-hosted control, while
the pulse represents errors and system activity.

## Identity

- **Name:** Faultbox
- **Description:** Self-hosted error and queue monitoring for Laravel.
- **Voice:** Clear, calm, and useful. Describe what happened and what action is
  available; avoid alarmist language.
- **Mark:** `web/static/favicon.svg`. Use the complete mark at small sizes; do
  not recolor individual paths or stretch it.
- **Wordmark:** "Faultbox" in the application's existing sans-serif type. The
  "box" portion uses the interface accent color.

## Core colors

| Use | Color |
|---|---|
| Mark background | `#13243A` |
| Signal blue | `#64B5E8` |
| Fault pulse coral | `#FF865E` |
| Interface accent | `#0071E3` light, `#0A84FF` dark |

The interface uses its existing neutral light and dark themes. Blue marks
navigation and focus; coral is reserved for the identity's signal and small
highlight details. Status colors remain governed by the interface palette.
